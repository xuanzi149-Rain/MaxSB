## 离线判断摊销

下表单位为服务商返回的输入加输出 token 数，**不是人民币费用**。历史真实回答中 12 次 ON 相对配对 OFF 共减少 398 token；评测本身仍支付了 OFF 与 ON 两侧调用成本。

| 成本口径 | 判断调用 | 判断 token | 减去已观测配对收益后的净收益 |
| --- | ---: | ---: | ---: |
| 六组最终批准样例的双向初判 | 12 | 5,457 | **-5,059** |
| 全部已知候选探索与追加判断 | 42 | 19,086 | **-18,688** |

不能忽略被拒绝、未批准和模糊候选的探索成本。24 小时批准有效期内，若六类有效命中均衡分布、每次继续达到历史平均 33.17 token 节省且设置成本不变，目标六组需约 **165 次有效命中**才有正 token 收益；一次性全部探索成本需约 **576 次有效命中**。这只是条件预测，输出长度节省含生成随机性；输入和输出价格不同，不能转换为财务盈亏平衡点。

同样假设下，180 次有效命中/24小时约净节省 513 token；30 次则净增加 4,462 token。过期后若重新审核需重新计入成本，不能永久摊薄一次审核。冻结集有效匹配为零，没有达到这些条件；没有用重复造流量来冒充长期业务使用。基础设施、人工成本及实际账单均未获得，不按零处理。
