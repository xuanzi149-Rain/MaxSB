用量增加主要集中在多轮题：输入增加 6475、输出增加 2628 token；其他场景合计输入减少 293、输出减少 14。生成的回答会进入后续历史，单次配对不能分离规则效果和模型输出波动的因果贡献。

`frozen-021` 问：“长60宽40高30厘米、实际10千克的包裹，其计费重量及南站实际限重是否满足？”固定策略从第 4 个候选取得 `F-volume`，计算体积重和计费重量为 12 千克，但缺少南站限重资料；动态策略误判为简单题，把候选数从 5 缩为 3，失去体积重公式，无法回答计费重量。证据召回从 0.5 降到 0。两侧都未召回 `F-south`，因此两侧回答均不完整，动态额外丢失一项可回答事实。

多段证据均值相同，是因为 `frozen-015` 从 0.5 升到 1；改善不能抵消新增回归。上述回答检查由 Codex 对照原始轨迹完成，不等于正式人工签收。关键词命中不能替代回答正确率或引用准确率。
