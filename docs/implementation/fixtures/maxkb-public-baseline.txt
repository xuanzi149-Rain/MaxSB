MaxKB 公开项目说明（任务 0 测试资料）
来源：https://github.com/1Panel-dev/MaxKB ，读取日期：2026-10-09。

MaxKB 是 1Panel-dev 开源的企业级智能体构建平台。项目使用 Python 和 Django 实现后端，使用 Vue 实现前端，采用 PostgreSQL 和 pgvector 保存数据与向量。

MaxKB 支持把文档上传并切分、向量化，构建检索增强生成（RAG）问答。它还提供工作流编排、工具调用和 MCP 相关能力。

本测试资料只用于验证原版“资料上传、检索、回答”路径。预期问题一：MaxKB 的后端与前端分别使用什么技术？预期答案：Python/Django 与 Vue。预期问题二：MaxKB 的向量数据库使用什么？预期答案：PostgreSQL/pgvector。
