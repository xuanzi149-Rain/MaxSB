## 行为与约束

`model_routing.enabled` 默认关闭，关闭时保留旧模型节点行为。开启仅支持应用顶层纯文本 AI 节点、同工作空间且状态正常的 LLM，首版使用原生 BaseChatOpenAI 兼容适配器。节点内工具/MCP/应用/技能、多模态、memory_policy、循环等组合拒绝。两个模型 ID 都登记依赖，并在保存/发布/运行入口校验。

低成本入口使用有限的完整操作语法（例如“提取姓名”“分类这段文本”，允许冒号后跟资料），无法识别的表达宁可走 high。历史依赖、复杂/混合任务及上游工具结果均走 high，包括 tool-workflow-lib-node。检索正文不参与选模判定。输出契约验证严格 JSON 对象、必需字段和绑定到当前检索结果的引用 ID，不代表事实正确性。

契约回答先缓冲后输出；低成本格式/字段/引用或受识别的超时/传输错误最多升级一次，消息保持一致。认证、未知错误、取消和缓冲超限不升级。失败草稿不会泄露；每次尝试有 ID、角色、配置模型、供应商返回模型、时长、失败与用量。SDK 内部重试关闭；每次执行拥有独立 HTTP 连接池，结束关闭。

用量未知按字段传播为 null，失败尝试也计入汇总。迁移 `0019_nullable_chat_usage` 使聊天记录 token 可空；节点详情、聊天来源和日志导出显示未知。旧仪表盘聚合仍是上游的使用统计，不能作为完整账单来源。真实部署前必须应用迁移；未在业务库应用。跨空间共享模型首版保守拒绝。

评测创建支持 low/high/routing 三策略，固定 low 不升级。三组需相同题集、契约、镜像、代码、工作区差异、评测源码及协议摘要；整体和每类正确率不降低，证据/引用无新增回归且实际费用完整、每成功任务成本下降才可报告优化。价格按调用绑定配置模型 ID 与名称；版本/来源/币种/有效期/缓存不完整为未知。参考核算与实际账单始终分开。正式比较脚本拒绝未 ready 的协议和覆盖既有输出。
