数据库备份为容器 `/opt/maxkb/rollback/closure-staging/pre-evaluation.dump`，已做新临时库恢复比对；不要用迁移回退当作常规功能关闭。旧 `/tmp/maxsb-task5-staging` 源码目录保留，可停止新服务后从 `/tmp/task5-stage-control.py serve` 回切旧 8084 版本。原 8080 服务和业务库没有应用本轮迁移。

8084 是本机单实例测试部署，未配置重启自动拉起、生产 TLS、长期监控或高并发容量。沙箱回环限制继续保留。下一次正式发布需在目标环境重新核对备份、迁移、worker 与子进程隔离，并完成任务 2/3/5 的剩余验收。
